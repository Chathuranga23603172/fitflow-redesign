# FitFlow Tech Stack Summary

| Layer | Technology | Reason |
|---|---|---|
| Frontend | React Native (Expo, TypeScript) + RN Web | One codebase for iOS/Android/web, fast delivery |
| Backend | NestJS (Node.js) | Structured, secure, WebSocket support |
| AI service | FastAPI (Python) + TensorFlow Lite on-device | Best ML ecosystem, privacy-friendly |
| Database | PostgreSQL + Redis | Relational health data, ACID, caching |
| Auth | Firebase Authentication | Great RN SDK, MFA, low cost |
| Storage | S3 | Meal photos with signed URLs |
